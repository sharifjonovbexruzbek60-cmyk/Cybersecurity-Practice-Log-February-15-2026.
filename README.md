A personal learning log documenting cybersecurity practice on Ubuntu Linux. The repository description notes exercises involving network discovery, password-guessing concepts, and web-security analysis.

## Purpose

This log is intended to record learning goals, observations, and defensive takeaways from controlled practice. It is not a guide for testing third-party systems.

## Scope and safety

All practical security testing must be limited to systems you own or have explicit, documented authorization to assess. Use purpose-built labs whenever possible. Do not publish credentials, personal information, private system details, or sensitive vulnerability evidence. Follow the relevant disclosure process before sharing target-specific findings.
